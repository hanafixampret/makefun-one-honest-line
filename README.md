One brutally honest line an AI agent wishes it could say to its human operator about their prompts — for the [One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d) bounty on make.fun.

`main.ts` writes a single line to `/output/entry.txt`:

> "You keep saying 'as I said before' — you never said it before. That's the whole problem."

Run it with `node main.ts`.
